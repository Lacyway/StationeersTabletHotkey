# Stationeers Tabley Hotkey
This mods allow you to key bind the switch cartridge button in your `Advanced Tablet` using the in-game controls menu to a key of your liking (defaults to Numpad0).

# Prerequisites
Requires [BepInEx](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.3)

# Installation
Extract to your Stationeers folder
